# [hyper2](https://crates.io/crates/hyper2)

[![crates.io](https://img.shields.io/crates/v/hyper2.svg)](https://crates.io/crates/hyper2)

A protective and efficient HTTP Client library for all.

- HTTP/1 and HTTP/2
- Asynchronous design
- Leading in performance
- Tested and **correct**
- Extensive production use
- Client APIs

## "Low-level"

hyper2 is a relatively low-level library intended as a building block for
HTTP Client libraries and applications.

If you are looking for a convenient HTTP client, then you may wish to consider
[rquest](https://github.com/0x676e67/rquest).
